# NextKDE v0.1.0

> 本文件描述 `0.1.0` 的发行内容；实际发布身份和验收记录以不可变 `v0.1.0` Tag
> 及对应的 GitHub Release 为准。默认由维护者验收后直接发布正式版，不要求公开 RC。

## 本版内容

本版覆盖 KDE Plasma Wayland 上的核心桌面：
顶部栏、Dock、应用启动器、搜索、通知、设置，以及配套平台服务、数据服务、
KWin 特效与窗口装饰。本轮另整合日历 UI、计算器和天气应用；可选锁屏及其余独立应用
仍需要另外声明验收范围。

应用整合见 [PR #234](https://github.com/SuceV587/NextKde/pull/234)：

- 合入 `codex/calendar-ui-iter-20261016`、`feat/calculator` 和 `claude/weather-app`。
- 计算器加入应用安装预设，补齐括号、科学运算、单位换算与键盘计算回归。
- 补齐日历、计算器与天气翻译，移除没有历史数据支撑的空气质量对比文案。
- CI 增加三套完整 KWin SDK（6.6、6.7、6.8）以及独立应用构建和测试。
- 日历过程截图不进入自动生成的源码发行归档；自动化日志和临时验收文件不进入发行树。

本轮 VM 已通过 128 项核心/界面测试和 20 项应用/PIM 测试，并完成应用安装、日历四视图与
编辑器、关联待办、计算器真实键盘输入及天气缓存夹具界面的检查。这些结果对应整合基线，
最终发行提交仍需对应 CI、默认安装、升级、重装回退及重启的完整记录。

发布与更新入口由 [PR #232](https://github.com/SuceV587/NextKde/pull/232) 提供，
对应 [版本追踪建议 #211](https://github.com/SuceV587/NextKde/issues/211)：

- 默认安装和更新选择 GitHub 最新正式 Release；开发版必须明确选择 `main`。
- `kosctl version` 分别显示实际部署版本与当前源码版本。
- 源码选择遇到本地修改、未完成的 Git 操作、无正式版或网络失败时停止，
  不覆盖工作区，也不自动沿用其他版本。
- 部署前备份并重建管理的 Shell/Settings 运行目录，避免升级和回退混入旧文件。
  部分部署失败时撤销版本记录，避免将残缺安装报告为完整版本。
- 只维护最新正式版；旧 Tag 保留用于追溯，不承诺长期补丁维护。

纳入基线的问题修复：

- [KWin 6.7.5 编译失败 #230](https://github.com/SuceV587/NextKde/issues/230)：
  检测 shader 有效性接口是否存在，避免调用该环境没有的 `GLShader::isValid()`。
- 修复 Dock 自动隐藏在交互输入与派生状态更新顺序不一致时可能一直保持显示的问题。

## 安装与升级

依赖及安装环境见 [开始使用](../GettingStarted.md)；
NixOS 用户另见 [NixOS 指南](../nixos-quickstart.md)。

下面的版本选择命令依赖已经发布的 `v0.1.0` Tag；发布前不可用：

```sh
./tools/kosctl update v0.1.0
./tools/kosctl install
./tools/kosctl start
./tools/kosctl version
```

源码选择需要 Git 和 Python 3.9+。`update` 只选择源码，安装和服务启动分别执行。
安装 KWin 原生插件后需要注销/重新登录或重启，不能把替换磁盘文件当成运行中插件已更新。

升级前保存个人配置；部署备份位于
`${XDG_STATE_HOME:-$HOME/.local/state}/kos/install-backups/`。
备份涵盖管理的 Shell/Settings 运行目录、`~/.config/kos` 和旧版本记录，
不包括完整系统插件、依赖或全部应用数据。磁盘空间由用户管理，备份不会自动清理。

## 已知限制与恢复

- 首版没有上一正式版可以推荐回退；以前的开发提交也不自动视为稳定版。
- 安装不是事务，没有一键回滚。构建失败、部分部署失败分别按日志处理；
  不要在新程序仍运行时覆盖旧格式配置。
- 在兼容的依赖和配置前提下，可重新安装一个经过验证的旧 Tag 恢复程序文件。
  早于本流程的 Tag 可能缺少运行目录清理逻辑，不能保证清理新版残留。
- 完整环境恢复依赖安装前的系统备份或 VM 快照。核心卸载恢复 Plasma 的流程已在 VM 验证，
  使用入口为 `./tools/kosctl uninstall`，随后注销/重新登录或重启。
- 首版不承诺所有发行版、可选组件或跨 schema 降级均已验证；应按上述范围选择是否安装。
